## 1. Кнопки и обработчики

### OK
- Все Link-компоненты в sidebar и bottom-nav ведут на существующие страницы
- Logout: вызывает `auth.signOut()` + редирект на `/login`
- FAB (быстрое добавление): открывает QuickAddSheet
- Добавить категорию: открывает диалог с формой
- Добавить цель: множество точек входа, все работают
- Тема: переключатель работает, сохраняется
- Акцент: 6 цветов, сохраняется в localStorage

### BUG
- **Нет подтверждения перед удалением** — цели, заметки, фото удаляются мгновенно без confirm-диалога
- Quick-add: после добавления задачи вызывает `window.location.reload()` вместо оптимистичного обновления

## 9. Бизнес-логика

### Прогресс категорий (today)
```
для каждой категории:
  для каждой цели:
    если привычка: done += выполненных задач; target += target_days
    если веха: target += 1; если completed — done += 1
  percent = (done / target) * 100
```
**Вердикт:** OK, но смешивание привычек и вех в одной категории может давать неожиданные проценты.

### Канбан-доска
- 4 колонки: Активные → Отложенные → Готово → Архив — OK
- Перемещение: кнопки в каждой карточке — OK
- Архив и Готово: сортировка по дате завершения (desc) — OK
- Фильтр по категориям — OK

### Стрик (streak) в календаре
```
Начинает с сегодня/вчера
Считает назад последовательные дни с 100% задач
Пропускает дни без задач (не ломает стрик)
```
**Вердикт:** OK, но семантика спорная — день без задач не ломает стрик.

### Матрица привычек
- Показывает только привычки (tracking_type = "habit") — OK
- Сетка: категории → цели → дни — OK
- Клик по ячейке = toggle задачи — OK
- Неделя/месяц переключение — OK

### Критичные пробелы в логике
1. **Нет дедлайн-предупреждений** — цели с target_date не показывают "осталось X дней" или "просрочено"
2. **Нет автогенерации задач из шаблонов** — шаблоны создаются, но ежедневные задачи из них не появляются автоматически
3. **Иерархия целей не используется** — parent_goal_id в схеме, но UI не показывает дерево
4. **Нельзя менять tracking_type** после создания цели
5. **Нет push-уведомлений** — настроены в manifest.json, но не реализованы
