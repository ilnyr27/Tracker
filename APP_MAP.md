# Tracker27 — Карта приложения

## Стек
Next.js 16 App Router · TypeScript · Tailwind CSS · shadcn/ui · Motion · Supabase self-hosted (`supabase.tracker27.ru`)

## Навигация

### Мобильный Bottom Nav (4 иконки)
| Иконка | Маршрут | Что делает |
|--------|---------|------------|
| Home | `/today` | Трекер — центральный экран |
| Grid3x3 | `/tabel` | Матрица жизни — сетка привычек |
| Target | `/goals` | Канбан — цели по статусам |
| BookOpen | `/journal` | Журнал — заметки + Список |

### Desktop Sidebar (слева)
- **Ежедневное**: Журнал · Трекер · Матрица жизни · Обзор
- **Цели**: Канбан
- **Записи**: Фото-дневник
- **Данные**: Таблицы

### Ещё (mobile, `/more`)
- Настройки, FAQ, Архив, Обзор, Фото-дневник, Таблицы

## Страницы

### `/today` — Трекер (главный экран)
**Файл:** `src/app/(app)/today/page.tsx`
- Greeting-карточка: дата, приветствие, прогресс-бар, стрик-флейм
- Категории жизни (10 штук) с % выполнения целей
- Цели внутри каждой категории (кружок-чекбокс + подзадачи)
- Стрик: считает дни с ≥1 выполненной задачей, пропускает пустые дни
- Быстрое создание целей/задач

### `/tabel` — Матрица жизни
**Файл:** `src/app/(app)/tabel/page.tsx`  
⚠️ Маршрут `/tabel` (не `/table`) — историческое название
- Сетка: строки = цели-привычки, столбцы = дни (неделя/месяц/год)
- Клетка = зелёная (сделано) / красная (пропущено) / пустая
- Режим "Записи": Excel-ячейки с текстом заметки
- Раздел "Прогресс по категориям": Радар / Круговая / Гистограмма
- **Важно**: outer wrapper имеет `overflow-x-hidden` — чарты всегда слева

### `/goals` — Канбан
**Файл:** `src/app/(app)/goals/page.tsx`
- Два режима: "Мои задачи" (без категории) / "По целям" (с категориями)
- Колонки: План (deferred) · В работе (active) · Готово (completed) · Архив (cancelled)
- Desktop: 4 колонки DnD drag-and-drop
- Mobile: filter pills (статус) + вертикальный список + **свайп между колонками** (порог 50px)
- Карточка цели: стрелки ← → для перемещения между колонками
- Фильтр категорий (только в режиме "По целям"): горизонтальная карусель

### `/journal` — Журнал
**Файл:** `src/app/(app)/journal/page.tsx`
- Лента заметок, сгруппированных по дате
- Input внизу: Textarea + кнопка отправки
- Поиск по тексту
- **Свайп влево** → переходит на `/sheets` (Список)

### `/sheets` — Список (вкладка Журнала)
**Файл:** `src/app/(app)/sheets/page.tsx`
- Кастомные списки с вложенными пунктами (tab_entries)
- Создание списков с именем + тип "list"
- **Свайп вправо** → переходит на `/journal`

### `/tables` — Таблицы
**Файл:** `src/app/(app)/tables/page.tsx`
- Кастомные таблицы (tab_type="table") из БД
- Создание: Excel-стиль — счётчик столбцов (A, B, C...) + счётчик строк (1, 2, 3...)
- При создании сразу генерируются N пустых строк
- Аккордеон-раскрытие, горизонтальный scroll внутри таблицы

### `/calendar` — Обзор
**Файл:** `src/app/(app)/calendar/page.tsx`
- Месячный календарь
- Цветные точки — активность по дням
- Тап на день → задачи и заметки за этот день

### `/photos` — Фото-дневник
**Файл:** `src/app/(app)/photos/page.tsx`
- Загрузка фото с привязкой к дате
- Storage bucket: `photos` в tracker Supabase (`supabase-tracker-db-1`)

### `/settings` — Настройки
- Тема (светлая/тёмная), акцент-цвет, категории, шаблоны задач

### `/auth/login` — Логин ✅ РЕАЛИЗОВАНО
**Файл:** `src/app/(auth)/login/page.tsx`
- Три режима внутри одного экрана: `login` / `signup` / `forgot`
- **"Забыл пароль?"** — кнопка строка 207, переключает в режим `forgot`
- В режиме `forgot`: отправляет reset-email через `supabase.auth.resetPasswordForEmail`
- Redirect после клика по ссылке в email → `/auth/callback?next=/reset-password`
- `/reset-password` страница существует: `src/app/(app)/reset-password/page.tsx`
- **НЕ нужно реализовывать — уже готово на 100%**

## База данных (Supabase tracker-specific)
- `categories` — 10 сфер жизни (здоровье, дом, деньги...)
- `goals` — цели (status: deferred/active/completed/cancelled, level: decade/year/month/week/day)
- `tasks` — задачи к целям (scheduled_date, is_done, completion_note)
- `task_templates` — шаблоны повторяющихся задач (recurrence rules)
- `notes` — заметки журнала (note_date, content)
- `custom_tabs` — вкладки Списка и Таблиц (tab_type: list/table, schema: {columns})
- `tab_entries` — строки/записи в кастомных вкладках (data: Record<string,unknown>)
- `photos` — метаданные фото (storage bucket: `photos`)

## Мобильный UX — ключевые правила
- Контент вмещается на один экран, не требует горизонтального скролла страницы
- Навигация между разделами = свайп пальцем (порог 50px, |dx| > |dy|)
- Горизонтальный скролл = только внутри изолированного контейнера (`overflow-x-auto`)
- Внешний wrapper страницы всегда `overflow-x-hidden`
