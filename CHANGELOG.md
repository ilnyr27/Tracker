# Life OS — Changelog

> Полный лог изменений проекта Life OS (Операционная Система Жизни).

---

## 2026-06-01

### Новые фичи
- **Диалог редактирования цели** — нажатие на карточку цели открывает полное окно: название, расписание (По дням недели / По дням и неделям / По числам), target_days. Загружает и обновляет `task_template`
- **Inline-редактирование списков** — клик по элементу списка в Листах → поле ввода, Enter/blur сохраняет
- **Кнопка удаления в списках** — всегда видна (раньше только при hover, на мобиле не работало)
- **Мульти-ячейки в таблицах** — Shift+click для выделения диапазона ячеек
- **Авто-инкремент дат** — при перетаскивании fill handle даты (`01.05.2026`) увеличиваются автоматически
- **Матрица по расписанию** — кружки показываются только в запланированные дни; незапланированные = бледные пунктирные

### Фиксы
- Таблица не растягивает страницу — скроллится горизонтально внутри карточки (`max-width: calc(100vw - 2rem)`)
- Шапка "Листы" + табы sticky при прокрутке
- Табы сеткой 2×N вместо горизонтальной ленты, обрезка названий до 20 символов
- Свободный текст переносится (`word-break: break-word`), не уходит вправо
- Название таба ограничено 200px с truncate
- Не создаётся лишний daily-шаблон при выборе "Вся неделя" (7 дней = ежедневная цель без шаблона)
- Убраны подсказки формул (мешали кликать ячейки)

## 2026-05-31

### Новые фичи
- **Расширенное расписание целей** — 3 режима: По дням недели (+ "Вся неделя"), По дням и неделям (weekdays × weeks), По числам месяца (1-31)
- **Тип `weekly_custom`** в RecurrenceRule — выбор конкретных недель + дней
- **Уведомления-напоминания** — polling каждую минуту, показ toast при наступлении `reminder_time`
- **Редактирование target_days** — клик по `done/target` в карточке цели → inline input
- **Экспорт данных** — JSON, XLSX, DOCX из настроек
- **Свайп-жесты для целей** — влево = архив, вправо = удалить (с подтверждением)
- **Drag-and-drop категорий** — перетаскивание для изменения порядка
- **Столбцы в таблицах** — добавление/удаление колонок, fill handle для автозаполнения
- **Статусная строка** — кликабельный текст под именем пользователя
- **Формулы в таблицах** — SUM, AVERAGE, MIN, MAX, COUNT, арифметика, ссылки на ячейки
- **Click-to-insert ссылки** — в режиме формулы клик по ячейке вставляет её адрес (A1, B2)
- **FAB (быстрое добавление)** — задачи, заметки, фото, ссылки на канбан/журнал/листы, кастомные табы
- **Режимы просмотра** — grid/list переключатель для категорий
- **Годовой/месячный/недельный режим матрицы** — переключение периодов
- **Emoji-пикер для категорий** — 300+ эмодзи в 10 группах

### Фиксы
- Канбан: drag-and-drop переписан на native HTML5 DnD (вместо dnd-kit)
- Канбан: форма цели всегда показывает категорию
- Графики: radar/donut/histogram — исправлены обрезки SVG, многострочные подписи
- Прогресс целей считается с даты создания, а не с начала месяца
- Матрица: данные persist при переключении периодов
- Quick-add: крестик не перекрывает шестерёнку настроек
- Quick-add: навигация к конкретному табу листов (`/sheets?tab=ID`)
- Emoji-пикер не выходит за экран на мобильном
- Кнопка "Создать" не уходит за экран при показе сетки "По числам" (`max-h-[85vh] overflow-y-auto`)

## Известные ограничения

- `window.location.reload()` в Quick Add после добавления задачи (оптимизация на потом)
- Нет toast-уведомлений при ошибках Supabase
- Нет "Забыл пароль" / смена пароля
- Push-уведомления настроены в manifest, но не реализованы
- Иерархия целей (parent_goal_id) не используется в UI
- Автогенерация задач из шаблонов не реализована
